# PathFlowEMS: Multi-Stage Onboarding & Approval enginee for Employee management

Streamlining the onboarding journey through automated multi-stage approval pipelines.

## Description
A full-stack Employee Management System specializing in dynamic onboarding workflows and multi-stage approval pipelines. Employees will be able to update personal information, upload
required documents for identification and work authorization. HR will be able to access employee information and make changes regarding the onboarding status.

## Core Features
### HR
Login / Navigation
Employee Profiles
Visa Status Management
Hiring Management

### Employee
Login / Navigation
Registration
Onboarding Application
Personal Information


## Tech Stack
-   **Frontend:** React, TypeScript, Redux, antd, CSS3, HTML5
-   **Backend:** Node.js, Express.js
-   **Database:** MongoDB
-   **Design Tool:** Figma
-   **Development Tool:** VS Code
